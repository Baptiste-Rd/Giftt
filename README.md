# Giftt

Listes de cadeaux partagées entre proches, sans serveur ni compte : les listes voyagent par SMS chiffrés de bout en bout, et le destinataire ne voit jamais qui a réservé quoi.

Ce dépôt public ne contient que les versions publiées de l'application Android. L'app y vérifie automatiquement les nouvelles versions.

## Installer

1. Télécharge `Giftt.apk` depuis la [ce lien](https://github.com/Baptiste-Rd/Giftt/raw/main/Giftt.apk).
2. Ouvre le fichier et autorise l'installation si Android le demande.
3. Si « Appli bloquée » s'affiche : « Plus de détails » puis « Installer quand même ».
4. Ouvre Giftt : l'app te guide pour le reste (SMS, notifications, mises à jour).

Les versions suivantes sont proposées directement dans l'app.
